# vortex-stonefish-interface

 Interface between the Stonefish simulator and the Vortex nodes 

## Installation
To build the required packages for the simulator, run:

 ```bash
 colcon build --symlink-install --packages-up-to stonefish_sim vortex_sim_interface 
 ```

 See [vortex-stonefish-sim](https://github.com/vortexntnu/vortex-stonefish-sim) for more information on the simulator itself.
